八条详细边：六条机制边，两条证据边

  1. 真实驾驶长尾难靠人类数据与脚本持续覆盖。
  2. 自博弈能制造在线分布，但模拟、观测、碰撞、奖励和策略前向必须整体 GPU 批处理，规模才足够大。
  3. 所有参与者共享条件策略；goal、奖励、形态、动力学与异常行为共同制造多样对手。
  4. 其他智能体的 goal 与 condition 对当前 agent 隐藏，同一可见状态可能对应不同意图，策略必须学会反应式应对。
  5. 集合观测用 Deep Sets 压成固定宽度；rollout 保存可重建 world state，minibatch 时再构造大型 observation。
  6. 成熟策略的大量 transition 绝对 GAE advantage 接近零，优势过滤把反向计算集中到影响更大的样本。
  7. 论文报告 10810^8108 到 101210^{12}1012 的能力阶段；这是实验支持关系，不是数学必然。
  8. 同一策略进入 CARLA、nuPlan、Waymax、WOSAC，并在限定配置的 long-form 模拟中报告长期鲁棒性。

02

Bottlenecks

四类瓶颈必须同时解决

A

行为覆盖

规则车、回放与人类数据难以持续制造长尾互动，自博弈让对手分布随策略共同演化。

B

模拟吞吐

只有完整闭环都能批处理，海量 world 才会转化为训练规模。

C

学习信号

大量普通 transition 的优势接近零，直接占用 PPO 反向算力。

D

观测显存

全局前向可涉及超过 10810^8108 个集合元素，完整保存 observation 不现实。

最小术语表

POSG

多个 agent 在只见局部信息的随机环境中同时决策。

World state / Observation

模拟器完整状态与单个策略真正可见输入不是同一对象。

Deep Sets

逐元素编码后做对顺序不敏感的集合聚合。

Jerk

加速度变化率；论文动作不是未来轨迹点。

Critic / Bootstrap / GAE

Critic 提供 value baseline；bootstrap 延续边界回报；GAE 汇总多步 TD residual。

Advantage filtering

按绝对 GAE advantage 的自适应阈值筛 transition。

On-policy

更新使用当前策略刚生成的数据。

Adapter

把 benchmark 的状态、时间和输出接口翻译到共享策略闭环。
