先给结论：它不是 VLM 后接动作头

π0 是一个 18 层、双 expert、decoder-only Transformer。图像与语言 token 走 PaliGemma/VLM expert，状态与带噪动作 token 走较小的 action expert；两套参数在每一层通过同一次 self-attention 交换信息。

3.3B论文近似总参数
18双 expert 共同深度
50 × d一次输出的动作块
10 steps默认 Euler 采样
关键纠偏它不是稀疏 MoE：没有学习型 router、top-k gating 或动态专家选择。token 到 expert 的分配由模态固定决定；“混合”发生在统一 attention，而不是路由概率。

1. 问题与设计动机

机器人策略要同时解决两个尺度的问题：一边是“看懂场景与语言意图”的互联网语义，一边是“以高频、连续、多峰分布输出精细动作”的控制问题。纯 VLM 擅长前者，却天然输出离散 token；常规回归头能输出连续值，却容易把多种合理动作平均掉。

π0 的解法是保留 PaliGemma 的视觉语言知识，同时引入专门处理状态和连续动作的 action expert，并用 conditional flow matching 学习条件动作分布。

这里 (I_t^i) 是第 (i) 路 RGB，ℓt\ell_tℓt​ 是语言 token，qtq_tqt​ 是本体状态，AtA_tAt​ 是未来 50 步的连续动作块。论文混合数据把状态/动作补到最大 (d=18)，当前代码默认模型容量则是 (d=32)。

4. 视觉与语言 Prefix

SigLIP-So400m/14

每路 RGB 经 14×14 patch embedding，得到 256 个 patch token。当前代码中的 So400m/14 配置为 width 1152、depth 27、MLP 4304、16 heads；随后用视觉 head 映射到 Gemma-2B 的 2048 宽度。

语言通过 PaliGemma 的共享词表 embedding 直接进入 2048 维。图像和文本拼成同一个双向 prefix block；缺失相机槽使用 image mask，而不是改变模型的三槽静态接口。

梯度事实train=False 传给 SigLIP 控制训练态行为，不等于冻结视觉参数。动作 loss 仍能经 prefix K/V 回传到 VLM 和视觉编码器；是否冻结由训练配置的 filter 决定。

5. State、Action 与 Timestep Suffix

一个状态 token

原始 π0 将本体状态 qt∈Rdq_t\in\mathbb R^dqt​∈Rd 经过 Linear(d,1024)，形成一个 action-expert token。它独立成 block，使其看不到随积分变化的动作。

每个动作一个 time-conditioned token

带噪动作先投影到 1024 维；标量时间经 1024 维 sinusoidal embedding 后复制到 50 个位置，与动作投影拼接，再经过 MLP。

一层内部究竟发生什么

  1. 各自 RMSNorm：VLM hidden 保持 2048，action hidden 保持 1024。
  2. 各自 Q/K/V：两套权重分别把不同宽度映射到相同的 8×256 query head 和 1×256 KV head 空间。
  3. 沿 token 维拼接：不是沿 channel 强行拼宽度；Q/K/V sequence 合并后做一次统一 MQA。
  4. Mask + softmax：attention logits 用 float32 累积，概率再 cast 回模型 dtype。
  5. 按 token 段切回：各 expert 使用自己的 output projection、残差、第二次 RMSNorm 与 gated-GELU FFN。
论文/代码冲突论文附录印作 num_heads=18，但官方代码是 8，且 (2048/256=8)。报告采用可执行代码的 8，并把论文数字视为疑似将 depth=18 误写到 head 字段。

7. 三块 Blockwise-Causal Mask

mask 的目的不是让整条序列自回归，而是保护预训练 prefix、隔离不随 flow 改变的状态，并让整段动作在一次 forward 内协同去噪。

Eq. 3bi=cumsum⁡(mi),Mqk=1[bk≤bq]⋅vqvkb_i=\operatorname{cumsum}(m_i),\qquad M_{qk}=\mathbf 1[b_k\le b_q]\cdot v_qv_kbi​=cumsum(mi​),Mqk​=1[bk​≤bq​]⋅vq​vk​

代码用 `mask_ar` 的累积和构造 block id。prefix 的标记全为 false；state 开新块；第一个 action 再开新块，余下 49 个 action 与它共享 block。结论是：50 个动作不是 causal chain，也不是逐 token 解码。

Mask 不等于梯度截断

action query 会读取 prefix K/V，因此动作 MSE 的梯度可以穿过统一 attention，更新 action expert，也能到达 VLM expert 和 SigLIP。prefix query 看不到 action 只限制前向依赖，不会自动阻断 prefix 参数参与 loss。只有训练配置的 freeze/LoRA filter 才决定哪些参数实际更新。

9. 推理：Prefix Cache + 10 次 Euler

  1. 预处理并编码图像、语言，运行 18 层 VLM prefix，保存每层 K/V。
  2. 采样 x1∼N(0,I)x_1\sim\mathcal N(0,I)x1​∼N(0,I)，shape 为 `[B,50,d]`。
  3. 由当前 (x_t) 与时间 (t) 重建 state+action suffix token。
  4. suffix query 同时读取 cached prefix K/V 与当前 suffix K/V，预测速度 vθ(xt,o)v_\theta(x_t,o)vθ​(xt​,o)。
  5. 用显式 Euler 更新动作；默认重复 10 次，得到 (x_0)。
Eq. 8xt+Δt=xt+Δt vθ(xt,o),Δt=−110x_{t+\Delta t}=x_t+\Delta t\,v_{\theta}(x_t,o),\qquad \Delta t=-\frac{1}{10}xt+Δt​=xt​+Δtvθ​(xt​,o),Δt=−101​
实现审计论文把 state 独立成 block，并说明其 K/V 可缓存；当前 JAX 代码实际只用 `embed_prefix` 缓存 image+text。每个 Euler step 调用 `embed_suffix`，state token 因而仍被重算。这是“设计允许的优化”与“固定 commit 已实现行为”的差异。
采样伪代码shape-aware
prefix_kv = transformer(prefix=[images, text])
x = normal(shape=[B, 50, d])
dt = -1 / num_steps
for t in [1.0, ..., 0.1]:
    suffix = embed(state, noisy_actions=x, time=t)
    v = action_out(transformer(suffix, kv_cache=prefix_kv)[-50:])
    x = x + dt * v
return x  # [B, 50, d]

11. 模块移除、工程代价与证据边界

如果拿掉关键模块

拿掉 VLM expert：论文的简化 baseline 改用较小视觉与语言编码器，失去互联网预训练语义；这不是只少一点参数，而是改变知识来源。拿掉 action expert：状态和动作必须共享 VLM 权重，论文指出独立 robotics weights 带来性能提升，但没有为每个实现细节提供独立 ablation。改成 causal action mask：会把一次并行动作块去噪改成顺序依赖，破坏当前 flow vector field 的联合建模假设。

代价：每次控制决策仍需一次视觉/prefix forward 加 10 次 action suffix forward；KV cache 省去重复视觉语言计算，但不是一次前向直接出动作。论文的 RTX 4090 时延是特定设置测量，不是当前机器或固定 commit 的性能保证。

不能从公开结构推出什么

代码结构不能证明所有机器人上的泛化效果，也不能替代训练数据、归一化统计和 checkpoint。当前报告没有重新训练、下载权重或实机执行，因此只验证架构与实现逻辑，不声称复现实验指标。

14. 最终心智模型

把 π0 想成一条拥有两套“内部宽度”的 18 层流水线：VLM expert 负责把图像与语言变成语义 K/V，action expert 负责把状态、噪声动作和时间变成控制 query；它们每层都在同一张受 block mask 约束的 attention 图里交流。训练时模型学的是“噪声动作应朝真实动作移动多快”；推理时固定观测语义被缓存，动作块从高斯噪声经过 10 次 Euler 更新落到连续控制序列。

对应到实现里，语义不是一个静态句向量，动作也不是 VLM 输出后的浅层回归头：交互发生在 18 层的每一层，这正是 π0 结构上最重要、也最容易被概念图掩盖的事实。
